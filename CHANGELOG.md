## [0.1.0] - 2026-09-04

### Added

- Cross-platform collection for operating system, uptime, time, CPU, GPU, memory, disk, network, battery, shell, and terminal information.
- Human-readable terminal output with supported image protocols and a Braille fallback.
- JSON output for scripts and integrations.
- Configurable artwork, visible system fields, and localized greetings.
- Release archives for macOS, Linux, and Windows with checksums.
